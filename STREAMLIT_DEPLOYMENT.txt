================================================================================

Step 1: Prepare Your Repository
────────────────────────────────────────────────────────────────────────

✓ Ensure code is pushed to GitHub:
  git add .

  git push origin main

✓ Verify file structure:
  ✅ streamlit_app.py (entry point)
  ✅ .streamlit/config.toml (configuration)
  ✅ requirements-streamlit.txt (dependencies)
  ✅ README.md (project description)


Step 2: Create Streamlit Cloud Account
────────────────────────────────────────────────────────────────────────

1. Go to: https://streamlit.io/cloud
2. Click "Sign Up" or "Login"
3. Use your GitHub account to authenticate
4. Grant Streamlit access to your repositories


Step 3: Deploy Your App
────────────────────────────────────────────────────────────────────────

1. On Streamlit Cloud dashboard, click "New App"
2. Select:
   - Repository: Pranay1004/random-positioning-machine-iist
   - Branch: main
   - Main file path: streamlit_app.py
3. Click "Deploy"
4. Wait 2-3 minutes for app to load

Your app will be available at:
  https://[Your-App-Name].streamlit.app


Step 4: Share Your Link

================================================================================
                      TROUBLESHOOTING DEPLOYMENT
================================================================================

App won't load:
  → Check requirements-streamlit.txt has all dependencies
  → Ensure streamlit_app.py is in root directory
  → Check GitHub connection in Streamlit dashboard

App is slow:
  → Reduce chart update frequency
  → Use @st.cache_data for expensive computations
  → Profile with: streamlit run streamlit_app.py --logger.level=debug

Missing data/files:
  → Use relative paths (./docs/file.txt)
  → Ensure files are committed to GitHub
  → Check .gitignore doesn't exclude needed files

Import errors:
  → Add packages to requirements-streamlit.txt
  → Use absolute imports: from src.module import func
  → Check sys.path manipulation in code


================================================================================
                         ENVIRONMENT VARIABLES
================================================================================

If you need sensitive data (API keys, etc.):

1. In Streamlit Cloud dashboard, go to Settings → Secrets
2. Add your secrets in TOML format:

   DATABASE_URL = "postgresql://..."
   API_KEY = "your-secret-key"

3. Access in code:
   import streamlit as st
   db_url = st.secrets["DATABASE_URL"]
